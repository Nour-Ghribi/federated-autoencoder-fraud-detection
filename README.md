# Federated Autoencoder Fraud Detection

Projet de detection d'anomalies sur transactions bancaires avec un autoencodeur entraine en apprentissage federe avec Flower.

## Contenu

- `Federated_Autoencoder(nour ghribi).ipynb` : notebook principal du projet.

## Dataset

Le fichier `creditcard.csv` n'est pas versionne dans Git car il depasse la limite de taille de GitHub. Il peut etre telecharge depuis Kaggle :

https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
